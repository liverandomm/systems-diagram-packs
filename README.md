# Systems Diagram Packs

Free, editable diagram packs from the YouTube channel on microservices and systems reliability (seen from operations / SRE).

Each folder holds D2 sources (`src/`), SVG (`svg/`) and PNG (`png/`). Render with `d2 --layout elk src/<file>.d2 out.svg` (D2 v0.9.0).
